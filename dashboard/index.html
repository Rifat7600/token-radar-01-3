# Protocol Category Chains TVL 7d Age Implied value List

How the radar ranks — the model, in one paragraph

Implied value = TVL × growth factor × age factor × launch factor × token factor. The growth factor follows the protocol's 7-day TVL change (clamped to −50%…+100%). The age factor rewards how long it has run with no token (up to +50% at 3 years). The launch factor discounts exchanges, bridges and wrapped or staked products (×0.25) and versioned names (×0.5) — the same rule the snapshot's watchlist uses. The token factor is ×1.5 for a protocol that records no token and ×0.35 for one whose token already trades: those are scored and left off this board, because their launch has already happened. The same formula runs in app.js as impliedValue(), recomputing every row's value from its own figures — the board and the code cannot disagree.

Farm plans are built from each protocol's category, chains, TVL and age: the same templates live in main.ts and in app.js. Every step names a cost and a time. A protocol "records no token" when DefiLlama carries no token for it — that is the record, not proof it has none. Nothing here predicts whether or when a token is issued.
